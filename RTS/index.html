01 / THE BIG IDEA

Correct means on time, too.

In real-time computing, the clock is part of the problem.

⏰
💡 Real-Time System

A computer system that receives input from the outside world and must respond within a fixed, stated deadline.

🧩

Logical correctness

The system calculated the right answer.

⏰

Temporal correctness

The right answer arrived before its deadline.

A correct answer that arrives too late is still a failure. Real-time is not “real fast”—it is predictable, even in the worst case. ✨

Release timeThe exact moment a task becomes ready because an event or interrupt arrived.
Execution timeThe CPU time needed to do the task’s work, not counting waiting.

DeadlineThe latest allowed finish time for the task.
JitterA small variation in the timing of task releases or responses.
04 / TASK RELEASE TYPES

How often does it ring?

Each task has its own rhythm.

🔔
🔁

Periodic

Repeats at a fixed period. Example: read a sensor every 100 ms.

🎲

Aperiodic

Triggered irregularly, with no guaranteed minimum gap. Example: a user button press.

🛟

Sporadic

Irregular, but has a known minimum gap. Example: emergency stop at most once per 100 ms.

Quick distinction: Aperiodic = irregular, no minimum gap promised. Sporadic = irregular, but the minimum gap is known. 🌟
05 / DEADLINE CONSEQUENCES

What if it’s late?

Compare how the result’s value changes.

🎯

🔴 Hard real-time

Late = potentially catastrophic
See the definition

Missing a deadline can cause catastrophic failure, heavy damage, or loss of life. After the deadline, the result’s value may become negative because it causes harm.

🟡 Firm real-time

Late = completely useless
See the definition

A late result is discarded. Its value drops instantly to zero at the deadline.

🟢 Soft real-time

Late = less useful
See the definition

A late result may still have some value, but performance degrades gradually over time.

06 / EMBEDDED SYSTEMS

Sense → decide → act.

A computer tucked into a machine, doing a dedicated job.

🤖
🧠 Embedded System

A dedicated computer hidden inside a bigger physical machine to perform a specific job.

Real-time control loop: the computer continuously senses the physical world, decides what to do, then changes the world.
